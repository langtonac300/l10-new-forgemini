From competent internal tool to corporation-grade software

A UX + graphic-design review of the Momentum Huddle app — the meeting runner, the new-member guide, and the weekly recap emails — with the ten highest-leverage next steps, ranked.

Reviewed 2026-06-30 8 design lenses 78 findings → 10 steps Bar: Linear · Notion · Asana · Monday

The verdict

It works — and it reads as a script someone bolted on, not software

Real flashes of product instinct live here: the to-scale priority-milestone timeline, optimistic UI, the two-click “armed confirm”, a 255-line onboarding guide. But the single thing holding it back most is that there is no shared source of truth for anything. The product contradicts itself surface-to-surface within a single week of a teammate’s use — and almost every finding traces back to four roots: no tokens, no component layer, no room mode, no accessible interaction baseline.

★ North star

A single Brady-blue, tokenized, component-built meeting product that reads identically in the app, the recap email, and the new-hire guide; runs the room from a full-screen present mode; is fully keyboard- and screen-reader-operable; and lets any mid-meeting mistake be undone in one click.

▶ If you only do three things

Foundation plus cheap polish — outsized perceived-quality, and they unblock the rest. #1 before the visual/email work; #2 and #3 in parallel.

1

One token source

Colour, space, type defined once — consumed by app, guide and email. The keystone every other visual fix depends on, and what kills the “three near-misses of the same blue” read.

2

Focus ring + keyboard

The cheapest highest-credibility win on the board. Crisp focus rings are a direct tell of real software, and it’s the floor of every procurement / VPAT check.

3

Undo + Wrap-up confirm

The defining safety pattern of Linear/Superhuman/Gmail. A mis-click in a live meeting is currently only fixable by hand-editing a sheet row.

⚠ Don’t break the Jira sync (merged 2026-06-30)

A one-way Momentum Huddle → Jira to-do sync now runs server-side and headless: a 10-minute trigger reads L10_Todos directly, creates a Jira issue for each OPEN to-do, and transitions it to Done when the to-do completes. Four steps below touch surfaces it reads — keep them Jira-safe: #3 / #10 must keep persisting Status to the sheet (the trigger reads it, not the client); #5 / #10 must keep the appended Jira Key/Jira Done columns intact (read by header name, append-only); #7 must preserve the Jira submenu in any L10Setup.gs menu refactor. The sync is one-way, so an undo (#3) reopens the sheet row but not a Jira issue already closed — word it accordingly, or have undo clear the Jira Done stamp.

The six cross-cutting themes

Every step is an instance of one of these. Fix the themes, not the symptoms.

Single source of truth (tokens)

One canonical token set consumed verbatim by app CSS, the guide, and the email builder. The keystone.

Component & render layer

Retire the innerHTML string-building + 67 inline styles for render helpers and consolidated CSS components.

Accessible interaction baseline

The floor every audit checks: focus ring, keyboard, text+glyph status, aria-live, dialog semantics, contrast.

In-room / projection mode

A deliberate present mode so the meeting lives on the shared screen, not the driver’s narration.

Trust & reversibility

Undo-on-toast, a confirm before the state-wiping Wrap-up, draft persistence, surgical reconciliation.

Honest data display

Sparklines that show magnitude-vs-goal, always-visible caveats, a health roll-up, trend in the exec email.

Honorable mentions

Strong, didn’t make the 10.

  • Real product mark. Replace the typed-string “Momentum Huddle” logo with an inline-SVG mark reused across app, guide and email.
  • One icon set. Swap functional emoji for a lightweight currentColor inline-SVG set matching the Experiment Hub.
  • Solve dialog semantics. role=dialog + aria-modal + Tab trap + focus restore — a 508 reviewer reproduces the focus leak in 30s.
  • Persistent meeting in the IA. A sticky-header chip with current segment + remaining time so the clock survives navigating away.
  • Content skeletons shaped like the tiles/rail/rows instead of the lone boot spinner.
  • Cheap VPAT line items: skip link, nav aria-label, aria-current=page on the active nav button.
  • Persist the Decide draft on incidental Esc/backdrop close — the hardest-won resolution wording is silently dropped today.
  • ResizeObserver on .ms-tl so the priority timeline relays out on embed-width change (the one real correctness bug).
  • Mirror the gold kudos card in the email Headlines section — the detection regex already exists.
  • Surface the Jira link in-app (new — from the 2026-06-30 sync). A synced to-do now carries a Jira Key but the app shows nothing — render a BNADM-398 ↗ chip (links to the issue) + a muted “syncing…” state, so the room sees a commitment is tracked on the board.
